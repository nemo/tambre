Lamps under each footswitch: green native · amber fallback chain only · grey unreachable. Order is C X U.

What this is. Tambre is an open registry of sound packs that bind to AI coding agent lifecycle events. Publish once; the pack works on Claude Code, Codex CLI and Cursor. Read-only surface: no login, no account, no dashboard. Publishing happens through the CLI with a keypair.

Coverage counts direct native support only. Fallback chains (permission.request → notification → turn.end) exist and are honoured by the adapters, but counting them makes every pack read 16/16 everywhere and the number stops meaning anything. Fallback-only reachability is the amber lamp.

Gain and throttle. Role defaults are baked into the runtime, not left to pack authors: boundary 1.0, cue 0.9, churn 0.2; churn throttles at 120 ms, everything else at 0. Polyphony is capped at 6, oldest dropped. Hover preview has its own 100 ms throttle so dragging across a bank does not machine-gun. Every rendered sound passes the mandatory limiter — ×0.9×volume, tanh(x×1.25)×0.8, trailing trim, 4 ms fade — so nothing here exceeds −1 dBFS.

Enclosure size is data. A pedal is as big as the number of hooks it binds. Brass Tacks binds all fourteen it can; Dead Room binds two.
